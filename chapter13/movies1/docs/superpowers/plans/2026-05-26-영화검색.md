# 영화 검색 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** OMDb API로 영화를 검색하고 무한 스크롤 목록을 보여주며, 항목 클릭 시 상세 페이지로 이동하는 React CSR 앱을 풀 테스트와 함께 구현한다.

**Architecture:** React Router(Data Mode)는 라우팅과 URL 검색어(`?s=`)만 담당하고 loader는 쓰지 않는다. TanStack Query가 데이터 페칭을 전담한다 - 검색은 `useInfiniteQuery`(무한 스크롤 누적), 상세는 `useQuery`. 전역 클라이언트 상태가 없어 Zustand는 도입하지 않는다.

**Tech Stack:** React 19, TypeScript, Vite 8, Tailwind 4, react-router v7, @tanstack/react-query v5, Vitest + React Testing Library + MSW.

**참고 문서:** `prds/영화검색.md`(기능), `prds/영화검색-테스트.md`(테스트)

- [ ] **Step 2: `src/test/msw/handlers.ts` 작성**

OMDb는 단일 엔드포인트에서 쿼리로 검색(`s`)과 상세(`i`)를 구분한다. 핸들러에서 쿼리를 읽어 분기한다. 페이지별로 10개를 생성해 무한 스크롤 누적을 검증할 수 있게 한다.

```ts
import { http, HttpResponse } from 'msw'
import type { MovieSummary } from '@/types/movie'

const BASE = 'https://www.omdbapi.com/'

// page 번호로 10개씩 가짜 영화 생성 (총 25개 = 3페이지)
const TOTAL = 25
function makePage(page: number): MovieSummary[] {
  const start = (page - 1) * 10
  const count = Math.min(10, TOTAL - start)
  if (count <= 0) return []
  return Array.from({ length: count }, (_, i) => {
    const n = start + i + 1
    return {
      Title: `Movie ${n}`,
      Year: '2020',
      imdbID: `tt${String(n).padStart(7, '0')}`,
      Type: 'movie',
      Poster: n % 5 === 0 ? 'N/A' : `https://example.com/poster${n}.jpg`
    }
  })
}

export const handlers = [
  http.get(BASE, ({ request }) => {
    const url = new URL(request.url)
    const s = url.searchParams.get('s')
    const i = url.searchParams.get('i')

    if (i) {
      return HttpResponse.json({
        Title: 'Movie Detail',
        Year: '2020',
        Rated: 'PG-13',
        Runtime: '120 min',
        Genre: 'Action',
        Director: 'Some Director',
        Actors: 'A, B, C',
        Plot: 'A plot.',
        Poster: 'https://example.com/detail.jpg',
        imdbRating: '8.0',
        imdbID: i,
        Type: 'movie',
        Response: 'True'
      })
    }

    if (s) {
      const page = Number(url.searchParams.get('page') ?? '1')
      const Search = makePage(page)
      if (Search.length === 0) {
        return HttpResponse.json({ Response: 'False', Error: 'Movie not found!' })
      }
      return HttpResponse.json({
        Search,
        totalResults: String(TOTAL),
        Response: 'True'
      })
    }

    return HttpResponse.json({ Response: 'False', Error: 'Incorrect IMDb ID.' })
  })
]
```

```ts
import type { MovieDetail, SearchResponse } from '@/types/movie'

const BASE_URL = 'https://www.omdbapi.com/'
const API_KEY = import.meta.env.VITE_OMDB_API_KEY

export async function searchMovies(query: string, page: number): Promise<SearchResponse> {
  const url = `${BASE_URL}?apikey=${API_KEY}&s=${encodeURIComponent(query)}&page=${page}`
  const res = await fetch(url)
  if (!res.ok) throw new Error(`검색 요청 실패: ${res.status}`)
  return res.json()
}

export async function getMovieDetail(imdbID: string): Promise<MovieDetail> {
  const url = `${BASE_URL}?apikey=${API_KEY}&i=${encodeURIComponent(imdbID)}`
  const res = await fetch(url)
  if (!res.ok) throw new Error(`상세 요청 실패: ${res.status}`)
  return res.json()
}
```

```ts
import type { SearchResponse } from '@/types/movie'

export function getNextPageParam(
  lastPage: SearchResponse,
  allPages: SearchResponse[],
  lastPageParam: number
): number | undefined {
  if (lastPage.Response === 'False') return undefined
  const loaded = allPages.reduce((sum, p) => sum + (p.Search?.length ?? 0), 0)
  const total = Number(lastPage.totalResults ?? 0)
  return loaded < total ? lastPageParam + 1 : undefined
}
```

```tsx
import type { ReactElement } from 'react'
import { render } from '@testing-library/react'
import { QueryClient, QueryClientProvider } from '@tanstack/react-query'
import { createMemoryRouter, RouterProvider } from 'react-router'

// 테스트마다 캐시/재시도 없는 새 QueryClient
function makeClient() {
  return new QueryClient({
    defaultOptions: { queries: { retry: false, gcTime: 0 } }
  })
}

// 단일 컴포넌트 렌더 (라우팅 불필요)
export function renderWithClient(ui: ReactElement) {
  return render(
    <QueryClientProvider client={makeClient()}>{ui}</QueryClientProvider>
  )
}

// 라우트 배열과 초기 경로로 렌더 (통합 테스트)
type RouteDef = Parameters<typeof createMemoryRouter>[0]
export function renderWithRouter(routes: RouteDef, initialPath: string) {
  const router = createMemoryRouter(routes, { initialEntries: [initialPath] })
  return render(
    <QueryClientProvider client={makeClient()}>
      <RouterProvider router={router} />
    </QueryClientProvider>
  )
}
```

## Task 10: MovieList 컴포넌트 + 무한 스크롤

**Files:**
- Create: `src/components/MovieList.tsx`

`MovieList`는 영화 배열과 무한 스크롤 콜백을 props로 받는다. 데이터 페칭은 HomePage가 하고, 여기서는 표시와 스크롤 감지만 한다(관심사 분리). 무한 스크롤은 `IntersectionObserver`로 sentinel을 감시한다.

- [ ] **Step 1: `src/components/MovieList.tsx` 구현**

```tsx
import { useEffect, useRef } from 'react'
import type { MovieSummary } from '@/types/movie'
import { MovieCard } from './MovieCard'

interface Props {
  movies: MovieSummary[]
  hasNextPage: boolean
  isFetchingNextPage: boolean
  onLoadMore: () => void
}

export function MovieList({ movies, hasNextPage, isFetchingNextPage, onLoadMore }: Props) {
  const sentinelRef = useRef<HTMLDivElement>(null)

  useEffect(() => {
    const el = sentinelRef.current
    if (!el || !hasNextPage) return

    const observer = new IntersectionObserver(entries => {
      if (entries[0].isIntersecting && !isFetchingNextPage) {
        onLoadMore()
      }
    })
    observer.observe(el)
    return () => observer.disconnect()
  }, [hasNextPage, isFetchingNextPage, onLoadMore])

  return (
    <div>
      <ul>
        {movies.map(movie => (
          <li key={movie.imdbID}>
            <MovieCard movie={movie} />
          </li>
        ))}
      </ul>
      <div ref={sentinelRef} data-testid="sentinel" />
      {isFetchingNextPage && <p>Loading more...</p>}
    </div>
  )
}
```

```tsx
  const query = searchParams.get('s') ?? ''

  const {
    data,
    isError,
    isLoading,
    hasNextPage,
    isFetchingNextPage,

  } = useMovieSearch(query)

      />

        <MovieList
          movies={movies}
          hasNextPage={hasNextPage}
          isFetchingNextPage={isFetchingNextPage}
          onLoadMore={fetchNextPage}
        />
      )}
```
