# 영화 검색 - 요구사항 문서

- 작성일: 2026-05-26
- 상태: 초안 (검토 대기)

## 1. 개요

OMDb API로 영화를 검색하고, 검색 결과 목록에서 항목을 선택하면 상세 정보를 보여주는
클라이언트 사이드 렌더링(CSR) 단일 페이지 애플리케이션이다.

핵심 흐름은 세 가지다.

1. 영어 키워드로 영화 검색
2. 검색 결과를 목록으로 출력하고 무한 스크롤로 다음 결과를 누적
3. 목록 항목을 클릭하면 해당 영화의 상세 페이지로 이동

## 2. 기술 스택

### 기존 (스캐폴딩 완료)

- Vite, React 19, TypeScript 6
- Tailwind CSS 4

### 도입 예정 패키지

- React Router (Data Mode, `createBrowserRouter`) - 경로 정의와 URL 검색어 관리
- TanStack Query - 서버 데이터 페칭과 캐싱 (`useInfiniteQuery`, `useQuery`)

### 역할 분담

| 도구           | 책임                                         | 비고             |
| -------------- | -------------------------------------------- | ---------------- |
| React Router   | 경로 정의, URL 검색어(`?s=`) 읽기/쓰기       | `loader` 미사용  |
| TanStack Query | OMDb API 호출, 캐싱, 무한 스크롤 페이지 누적 | 데이터 페칭 전담 |

데이터 페칭을 TanStack Query가 전담하므로 React Router의 `loader`는 사용하지 않는다.
React Router는 라우팅과 URL 상태 관리 용도로만 쓴다.

## 3. 기능 요구사항

### FR-1. 영화 검색

- 검색창에 영어 키워드를 입력하고 엔터 또는 검색 버튼을 눌러 실행한다.
- 검색 실행 시 검색어를 URL 쿼리스트링 `?s=검색어`에 반영한다.
- 검색어가 비어 있으면 API를 호출하지 않는다.
- OMDb는 영어 검색만 지원한다. 한글 등으로 검색하면 결과가 없을 수 있으며,
  이 경우 FR-4의 "검색 결과 없음" 상태로 처리한다.

### FR-2. 검색 결과 목록 (무한 스크롤)

- OMDb 검색은 한 페이지에 10개씩 반환한다.
- 검색 결과를 목록으로 출력한다. 각 항목은 최소한 포스터, 제목, 연도를 식별할 수 있어야 한다.
- 목록 끝(스크롤 바닥)에 도달하면 자동으로 다음 페이지를 불러와 기존 목록에 누적한다.
  (`useInfiniteQuery`의 `fetchNextPage`)
- 더 불러올 페이지가 없으면 추가 요청을 하지 않는다.
  전체 결과 수(`totalResults`) 대비 로드한 개수로 다음 페이지 존재 여부를 판단한다.

### FR-3. 상세 보기

- 목록 항목을 클릭하면 해당 영화의 상세 페이지(`/movie/:imdbID`)로 이동한다.
- 상세 페이지는 `imdbID`로 OMDb 상세 정보를 조회해 표시한다.
- 상세 페이지에서 검색 목록으로 돌아갈 수 있어야 한다.

### FR-4. 상태 및 예외 처리

- 검색 전 초기 상태: 검색을 안내하는 표시를 보여준다.
- 로딩 중: 검색/상세 데이터를 불러오는 동안 로딩 표시를 보여준다.
- 검색 결과 없음: OMDb 응답이 결과 없음일 때 빈 결과 안내를 보여준다.
- 에러: 네트워크 오류나 API 오류 시 에러 표시를 보여준다.
- 포스터 없음: 포스터 값이 `"N/A"`인 경우 대체 표시(플레이스홀더)를 사용한다.

## 4. 라우트 구조와 데이터 흐름

### 라우트

| 경로             | 화면                                | 데이터 소스                                    |
| ---------------- | ----------------------------------- | ---------------------------------------------- |
| `/?s=검색어`     | 검색 입력 + 결과 목록 (무한 스크롤) | `useInfiniteQuery(['search', s])` -> OMDb `s=` |
| `/movie/:imdbID` | 상세 페이지                         | `useQuery(['movie', imdbID])` -> OMDb `i=`     |

### 데이터 흐름

검색 목록 (`/`):

1. 검색창 입력 후 엔터/버튼 -> `setSearchParams({ s })`로 URL 갱신
2. `useSearchParams`로 읽은 `s`를 `useInfiniteQuery`의 쿼리 키로 사용
3. 결과 목록 렌더
4. 스크롤이 바닥에 닿으면 `fetchNextPage`로 다음 10개를 불러와 누적

상세 (`/movie/:imdbID`):

1. 목록 항목 클릭 -> `<Link to={`/movie/${imdbID}`}>`로 이동
2. 상세 페이지에서 `useParams`로 `imdbID`를 읽어 `useQuery` 실행
3. 상세 정보 렌더

상태 복원:

- 페이지 새로고침이나 링크 공유 시 URL의 `s` 값으로 검색 상태를 복원한다.

## 5. OMDb API 연동

### 엔드포인트

- 베이스 URL: `https://www.omdbapi.com/` (`www` 포함이 정확하다)
- 검색: `https://www.omdbapi.com/?apikey={KEY}&s={검색어}&page={페이지}`
- 상세: `https://www.omdbapi.com/?apikey={KEY}&i={imdbID}`

### API 키

- 키 값 `7035c60c`는 코드에 하드코딩하지 않고 환경 변수 `VITE_OMDB_API_KEY`로 분리한다.
- `.env` 파일에 정의하고, `.env`는 `.gitignore`에 포함한다.

### 응답 형식 (참고)

검색 응답:

```json
{
  "Search": [
    {
      "Title": "Batman Begins",
      "Year": "2005",
      "imdbID": "tt0372784",
      "Type": "movie",
      "Poster": "https://..."
    }
  ],
  "totalResults": "638",
  "Response": "True"
}
```

상세 응답 (주요 필드):

```json
{
  "Title": "Batman Begins",
  "Year": "2005",
  "Rated": "PG-13",
  "Runtime": "140 min",
  "Genre": "Action, Crime, Drama",
  "Director": "Christopher Nolan",
  "Actors": "Christian Bale, Michael Caine, Ken Watanabe",
  "Plot": "After witnessing his parents' death, ...",
  "Poster": "https://...",
  "imdbRating": "8.2",
  "Response": "True"
}
```

결과 없음 응답:

```json
{ "Response": "False", "Error": "Movie not found!" }
```

- 검색 결과 누적과 무한 스크롤은 `totalResults`(전체 결과 수)를 기준으로 다음 페이지
  존재 여부를 계산한다. (로드한 개수 < `totalResults`이면 다음 페이지 있음)
- `Response`가 `"False"`인 경우 FR-4의 "검색 결과 없음"으로 처리한다.

## 6. 범위 외 (Out of Scope)

- 화면 레이아웃, 카드 디자인, 색상 등 시각 디자인
- 상세 페이지에 표시할 구체적 필드 선택과 배치
- 컴포넌트 분해 등 세부 구현 구조 (구현 단계에서 결정)
- 즐겨찾기, 최근 검색어, 정렬/필터 등 추가 기능
- 로그인, 사용자 계정, 백엔드 서버

## 7. 성공 기준

- [ ] 영어 키워드로 검색하면 결과 목록이 출력된다.
- [ ] 검색어가 URL `?s=`에 반영되고, 새로고침해도 검색 결과가 복원된다.
- [ ] 스크롤을 내리면 다음 페이지가 자동으로 누적되고, 마지막 페이지 이후로는 추가 요청이 없다.
- [ ] 목록 항목을 클릭하면 `/movie/:imdbID` 상세 페이지로 이동하고 상세 정보가 표시된다.
- [ ] 로딩, 에러, 검색 결과 없음, 포스터 없음 상태가 각각 처리된다.
- [ ] API 키가 환경 변수로 분리되어 있고 `.env`가 버전 관리에서 제외된다.
