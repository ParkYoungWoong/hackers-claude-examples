# 테스트 규칙

테스트는 vitest + @testing-library/react로 작성한다. 실행은 `npm run test`(`vitest run`)다.

## 언제 작성하나

- 새 기능이나 컴포넌트를 추가하면 같은 폴더에 `*.test.tsx`를 함께 만든다(예: `TodoList.tsx` → `TodoList.test.tsx`).
- 기능을 수정하면 관련 테스트도 함께 갱신한다.
- 구현이 끝나면 `npm run test`로 전부 통과하는지 확인한 뒤 완료로 본다.

## 어떻게 작성하나

- 구현 세부가 아니라 **사용자 관점의 동작**을 테스트한다. 요소는 역할/텍스트로 찾는다: `getByRole`, `getByText`, `getByLabelText`.
- 클릭 등 상호작용은 `@testing-library/user-event`를 쓴다.
- 한 `it`은 한 가지 동작만 검증한다. 설명은 한국어로 "무엇을 한다"를 적는다.

## 무엇을 테스트하나 (예시)

- 할 일 추가: 입력 후 제출하면 목록에 항목이 나타난다.
- 할 일 삭제: 삭제 버튼을 누르면 해당 항목이 사라진다.
- 완료 토글: 항목 텍스트를 클릭하면 `todo-item--done`이 토글된다.

CSS 클래스 같은 세부 대신, 가능하면 "사라진다 / 보인다 / 완료로 표시된다"처럼 사용자가 인지하는 결과를 단언한다.
