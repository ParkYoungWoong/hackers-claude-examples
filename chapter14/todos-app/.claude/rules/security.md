# 보안 규칙

이 앱은 프론트엔드 SPA다. 표면은 작지만 다음 기본 방어를 항상 지킨다.

## XSS 방지

- `dangerouslySetInnerHTML`을 쓰지 않는다. 사용자 입력이나 외부 데이터를 HTML로 직접 주입하지 않는다. 텍스트는 JSX 기본 렌더링(자동 이스케이프)으로 표시한다.
- `eval`, `new Function`, 문자열을 코드로 실행하는 패턴을 쓰지 않는다.

## 비밀 정보

- API 키, 토큰, 비밀번호 등을 소스 코드에 하드코딩하지 않는다. 환경 변수(`import.meta.env.VITE_*`)로 주입한다.
- `VITE_` 접두사가 붙은 환경 변수는 빌드 결과에 그대로 노출된다. 진짜 비밀(서버 시크릿)은 절대 클라이언트 코드에 두지 않는다.

## 입력과 저장

- 외부/사용자 입력은 신뢰하지 않는다. 표시 전 트림하고, 길이 등 기본 검증을 한다(예: 빈 문자열 거부).
- 외부에서 받은 URL을 `href`/`src`에 쓸 때는 `http(s)` 스킴인지 확인한다(`javascript:` 차단).
- 민감 정보를 `localStorage`/`sessionStorage`에 저장하지 않는다.
