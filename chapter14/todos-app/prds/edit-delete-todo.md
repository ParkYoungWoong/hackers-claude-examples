# 할 일을 수정하고 삭제하는 기능

## 사용 시나리오

### 수정

1. 할 일 목록의 각 항목에 수정 버튼이 표시된다
1. 수정 버튼을 누르면 그 항목이 입력창으로 바뀐다
1. 내용을 고치고 엔터 키를 누르거나 저장 버튼을 누르면 수정된 내용을 저장한다
1. 저장하는 동안 로딩 애니메이션이 표시된다
1. 저장이 완료되면 다시 일반 항목으로 표시한다

### 삭제

1. 할 일 목록의 각 항목에 삭제 버튼이 표시된다
1. 삭제 버튼을 누르면 그 할 일을 목록에서 제거한다

## 별도 파일로 구분

- 할 일 항목(수정/삭제 버튼 포함)을 표시하는 코드
