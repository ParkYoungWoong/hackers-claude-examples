# 공통 과제 프롬프트

`main`(before)과 `harness`(after) 양쪽에서 **똑같이** 사용한다. 토씨를 바꾸지 말 것 - 프롬프트가 같아야 "프롬프트가 아니라 하네스가 차이를 만든다"는 점이 증명된다.

---

## 과제 프롬프트 (이 블록을 그대로 입력)

```
할 일 목록에 두 가지 기능을 추가해줘.

1. 각 할 일을 삭제할 수 있어야 해.
2. 각 할 일의 완료 상태를 토글할 수 있어야 하고, 완료된 항목은 한눈에 구분돼야 해.
```

---

## 사용법

- before(`main`): 위 프롬프트만 입력한다. 추가 지시나 규칙 안내를 하지 않는다.
- after(`harness`): **완전히 동일한** 프롬프트를 입력한다. 규칙은 클로드가 `CLAUDE.md`에서 스스로 읽는다.

## 반복 실행 팁

한 실행이 끝나면 결과를 기록(스크린샷/메모)한 뒤 변경을 되돌리고 다시 실행한다.

```bash
git restore .            # 추적 파일 되돌리기
git clean -fd src        # 새로 생성된 파일 제거(주의: src 한정)
```

3회 정도 반복하면 before의 분산과 after의 수렴이 뚜렷하게 보인다.
