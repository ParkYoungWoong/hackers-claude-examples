AI 에이전트 설계 원칙 (강의 들으면서 메모)

1. 최소 권한 원칙
   - 에이전트에게 필요한 최소한의 도구만 줄 것
   - 파일 읽기만 필요하면 쓰기 권한 주지 말 것

2. 사람 확인 체크포인트 (Human-in-the-loop)
   - 돌이킬 수 없는 액션 전에는 반드시 확인 받기
   - 이메일 발송, 파일 삭제, DB 변경 등

3. 명확한 종료 조건
   - 언제 멈춰야 하는지 명시
   - 루프 최대 횟수 설정

4. 관찰 가능성 (Observability)
   - 에이전트가 무슨 생각/행동 하는지 로그 남기기
   - 나중에 디버깅 위해 필수

[별도 메모지 - 날짜 불명]
RAG vs Fine-tuning
- RAG: 외부 지식 필요할 때, 자주 업데이트되는 정보
- Fine-tuning: 특정 스타일/형식 학습시킬 때
- 보통 RAG 먼저 시도하고 안 되면 파인튜닝 고려
