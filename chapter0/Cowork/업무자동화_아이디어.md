# 업무 자동화 아이디어 메모
작성: 2024-09-25, 마지막 수정: 2024-11-20

## 자동화하고 싶은 것들

### 1. 주간 리포트 생성
- Jira 티켓 -> 이번 주 완료/진행 자동 정리
- Google Calendar 일정 -> 회의 요약
- Slack 채널 -> 주요 결정사항 추출
- 위 3개 합쳐서 주간 리포트 초안 자동 생성

### 2. 코드 리뷰 보조
- PR 올라오면 자동으로 기본 검토
- 보안 취약점, 성능 문제 1차 필터링
- 리뷰어에게 포인트 미리 알려주기

### 3. 고객 문의 분류
- 인입 문의 카테고리 자동 분류
- FAQ 해당하면 자동 답변 초안
- 긴급도 판단해서 우선순위 지정

### 4. 문서 동기화
- 코드 변경되면 관련 문서 업데이트 알림
- Confluence 페이지와 실제 코드 불일치 감지

## 이미 해본 것

- 이메일 뉴스레터 요약 -> 슬랙 채널 자동 발송
