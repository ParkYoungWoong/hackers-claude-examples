# 멀티 에이전트 협업 패턴 메모
작성일: 2024-11-15

## 왜 멀티 에이전트인가?
- 단일 에이전트는 복잡한 작업에서 컨텍스트 한계에 걸림
- 역할 분리로 각자 전문화 가능
- 병렬 처리로 속도 향상

## 주요 패턴

### Orchestrator - Worker
- Orchestrator가 전체 계획 수립
- 각 Worker에게 세부 작업 위임
- Claude Code의 Agent tool이 이 방식

### Peer-to-Peer
- 에이전트들이 서로 리뷰하고 피드백
- 코드 리뷰, 글쓰기 검수에 적합

### Pipeline
- A -> B -> C 순서로 출력이 다음 입력이 됨
- 데이터 가공, 번역 후 요약 등에 활용

## 실제 써보고 싶은 것
- CrewAI로 리서치 에이전트팀 구성해보기
- 기획자/개발자/QA 역할 나눠서 자동화
